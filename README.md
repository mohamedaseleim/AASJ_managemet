# مجلة أرشيف العلوم الزراعية (AASJ)
## Archives of Agriculture Sciences Journal - Editorial & Manuscript Management System

منظومة إلكترونية متكاملة لإدارة التحرير والنشر العلمي والتحكيم الأكاديمي لمجلة **أرشيف العلوم الزراعية (AASJ)** الصادرة عن **كلية الزراعة (فرع أسيوط)، جامعة الأزهر، مصر** بالتعاون مع **بنك المعرفة المصري (EKB)**.

- **الترقيم الدولي للنسخة المطبوعة:** `Print ISSN: 2535-1680`
- **الترقيم الدولي للنسخة الإلكترونية:** `Online ISSN: 2535-1699`
- **الدورية:** ٣ أعداد سنوياً (أبريل - أغسطس - ديسمبر)
- **الموقع الرسمي لبنك المعرفة:** [https://aasj.journals.ekb.eg](https://aasj.journals.ekb.eg)

## المزايا والوظائف الرئيسية

1. **إدارة المخطوطات والأبحاث:** تتبع كامل لدورة حياة البحث منذ الاستلام وحتى القبول والنشر النهائي في الأعداد والمجلدات.
2. **التحكيم العلمي المزدوج المعمى (Double-Blind Peer Review):** إدارة وتكليف المحكمين الأكاديميين المعتمدين وسرية تقارير التحكيم.
3. **الأقسام والتخصصات العلمية السبعة (AASJ 7 Sections):** توزيع تحريري متخصص للأقسام السبعة للكلية بمحررين تنفيذيين معتمدين.
4. **التقارير البيانية وتقييم الأداء التحريري (Recharts Analytics):** رسوم بيانية شهرية للأبحاث المستلمة والمقبولة والمرفوضة ونسب الإنجاز وزمن التحكيم.
5. **نظام خطابات القبول الرسمية:** توليد خطابات قبول رسمية قابلة للطباعة بتوقيع عميد الكلية ورئيس التحرير ورمز التحقق QR.
6. **التدفقات المالية وسندات القبض:** متابعة رسوم الفحص والنشر والمكافآت وتوليد إيصالات مالية معتمدة.
7. **إدارة المستخدمين والصلاحيات (11 دور وظيفي):** بنية صلاحيات دقيقة (المشرف العام، رئيس التحرير، مدير التحرير، سكرتير المجلة، محرر تنفيذي، محكم، باحث، ومسؤول النظام).
8. **الأمان وحماية بيانات الدخول:** حجب أي بيانات دخول تجريبية وإتاحة تغيير كلمة المرور للمشرف ولجميع الحسابات بأمان تام.
9. **تطبيق ويب تقدمي (PWA):** قابل للتثبيت على الهواتف الذكية وأجهزة الحاسوب مع دعم العمل دون اتصال بالإنترنت.

## دليل النشر الشامل عبر GitHub Pages وقواعد البيانات

للحصول على الشرح المفصل والدقيق خطوة بخطوة لنشر التطبيق مجاناً عبر **GitHub Pages**، وتهيئة قواعد البيانات السحابية (**Firebase Firestore**) أو العلائقية (**PostgreSQL / Supabase**)، يرجى الاطلاع على الدليل الكامل:

👉 **[اضغط هنا لفتح دليل النشر الشامل وقواعد البيانات: DEPLOYMENT_GITHUB_PAGES_GUIDE.md](./DEPLOYMENT_GITHUB_PAGES_GUIDE.md)**

الملفات الملحقة بقواعد البيانات في المستودع:
- `database/schema.sql`: مخطط قاعدة البيانات العلائقية الكامل (PostgreSQL DDL) بجميع الجداول والمؤشرات والمفاتيح.
- `database/firestore.rules`: قواعد الأمان والتحقق السحابية للإنتاج لـ Google Firebase Firestore.
- `.github/workflows/deploy.yml`: إعدادات البناء والنشر التلقائي عبر GitHub Actions.
- `public/404.html`: معالجة مسارات الـ SPA على GitHub Pages لمنع أخطاء التوجيه.

## التشغيل والتطوير محلياً (Local Development)

```bash
# تثبيت الاعتماديات

# تشغيل بيئة التطوير
npm run dev

# فحص وتدقيق الأكواد TypeScript
npm run lint
```
